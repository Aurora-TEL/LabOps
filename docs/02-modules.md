# LabOps 功能模块设计

## 1. 模块总览

LabOps 按照中后台系统常见的信息架构划分为 7 个一级模块：

| 模块 | 说明 |
| --- | --- |
| 首页看板 | 展示实验室设备运行态势和核心指标 |
| 预约管理 | 管理设备预约申请、审核、取消和完成 |
| 设备管理 | 维护设备台账、设备分类、设备状态和设备详情 |
| 报修运维 | 管理故障报修、维修工单和维护记录 |
| 数据分析 | 分析设备利用率、预约热度、故障率和维修效率 |
| 基础数据 | 管理实验室、设备分类、故障类型、状态字典 |
| 系统管理 | 管理用户、角色、权限和系统配置 |

## 2. 首页看板

首页看板是复试展示的第一屏，需要直观体现“智能实验室运营平台”的项目质感。

### 2.1 指标卡片

- 设备总数。
- 在线设备数。
- 今日预约数。
- 本周预约数。
- 待审核预约数。
- 待处理报修数。
- 平均设备利用率。
- 平均维修时长。

### 2.2 图表区域

- 近 7 日预约趋势折线图。
- 设备利用率趋势折线图。
- 设备状态分布环形图。
- 预约状态分布柱状图或环形图。
- 故障类型分布图。
- 实验室使用热度排行。

### 2.3 列表区域

- 最新预约申请。
- 最新报修记录。
- 待处理工单。
- 异常设备列表。

### 2.4 页面风格

- 左侧固定导航。
- 顶部栏展示当前用户、通知、时间和系统状态。
- 内容区使用浅色卡片、蓝色科技感强调色和少量绿色、橙色、红色状态色。
- 图表不追求复杂动画，重点保证数据层次清晰。

## 3. 预约管理

### 3.1 设备可预约查询

- 按实验室筛选设备。
- 按设备分类筛选设备。
- 按设备状态筛选设备。
- 查看设备已被预约的时间段。

### 3.2 预约申请

用户提交预约时需要填写：

- 预约设备。
- 开始时间。
- 结束时间。
- 使用目的。
- 参与人数。
- 备注说明。

系统提交前需要校验：

- 设备是否存在。
- 设备状态是否允许预约。
- 时间段是否冲突。
- 开始时间是否早于结束时间。
- 申请人是否具备预约权限。

### 3.3 预约审核

预约状态包括：

| 状态 | 说明 |
| --- | --- |
| pending | 待审核 |
| approved | 已通过 |
| rejected | 已拒绝 |
| cancelled | 已取消 |
| completed | 已完成 |

教师或实验室管理员可审核预约。审核通过后，预约进入生效状态；审核拒绝时需要填写拒绝原因。

### 3.4 预约列表

预约列表支持：

- 按状态筛选。
- 按设备筛选。
- 按申请人筛选。
- 按预约日期筛选。
- 查看详情、审核、取消、完成。

## 4. 设备管理

### 4.1 设备台账

设备台账字段包括：

- 设备编号。
- 设备名称。
- 设备分类。
- 所属实验室。
- 负责人。
- 设备状态。
- 健康评分。
- 购置日期。
- 设备描述。

### 4.2 设备状态

| 状态 | 说明 |
| --- | --- |
| idle | 空闲，可预约 |
| in_use | 使用中 |
| maintenance | 维护中 |
| fault | 故障 |
| disabled | 停用 |

### 4.3 设备详情

设备详情页包含：

- 基础信息。
- 当前状态。
- 今日预约时间线。
- 历史预约记录。
- 报修记录。
- 维护记录。
- 利用率统计。

### 4.4 设备分类

分类可包括：

- 分析检测类。
- 加工制造类。
- 电子信息类。
- 生物实验类。
- 通用仪器类。

## 5. 报修运维

### 5.1 报修记录

用户提交报修时需要填写：

- 故障设备。
- 故障类型。
- 故障描述。
- 故障图片地址，占位即可。
- 紧急程度。

报修状态包括：

| 状态 | 说明 |
| --- | --- |
| submitted | 已提交 |
| accepted | 已受理 |
| assigned | 已派单 |
| processing | 处理中 |
| finished | 已完成 |
| closed | 已关闭 |

### 5.2 维修工单

管理员可根据报修记录创建工单。工单包含：

- 关联报修记录。
- 处理人。
- 优先级。
- 计划处理时间。
- 处理过程。
- 维修结果。
- 完成时间。

### 5.3 维护记录

维护记录用于沉淀设备生命周期信息：

- 定期保养。
- 故障维修。
- 备件更换。
- 校准检测。
- 停用启用。

## 6. 数据分析

### 6.1 设备利用率分析

计算设备在指定时间范围内的预约占用时长和可用总时长，得到利用率。支持按设备、实验室、分类进行统计。

### 6.2 预约热度分析

展示不同实验室、不同设备、不同日期的预约热度，帮助管理员判断资源是否紧张。

### 6.3 故障分析

展示故障类型分布、故障设备排行、故障发生趋势和平均维修时长。

### 6.4 运营报表

支持按周、月维度生成运营摘要：

- 预约总数。
- 完成预约数。
- 设备平均利用率。
- 报修总数。
- 平均维修时长。
- 高风险设备列表。

## 7. 基础数据

基础数据模块用于支撑核心业务：

- 实验室管理。
- 设备分类管理。
- 设备状态字典。
- 故障类型字典。
- 工单优先级字典。

## 8. 系统管理

系统管理模块用于用户和权限控制：

- 用户管理。
- 角色管理。
- 权限管理。
- 菜单管理。
- 登录日志，占位设计即可。
