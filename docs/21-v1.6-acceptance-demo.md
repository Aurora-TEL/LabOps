docker compose up -d
docker compose exec backend alembic upgrade head
docker compose exec backend python -m app.db.seed
docker compose run --rm -e PYTHONDONTWRITEBYTECODE=1 backend pytest -p no:cacheprovider
docker build --target build -t labops-frontend-build-check ./frontend

## 页面验收

1. 使用 `admin / password` 登录。
2. 进入“设备状态”页面。
3. 点击任意设备卡片的“详情”。
4. 查看设备温度、计划保养、维护记录数量和维护台账列表。
5. 新增一条例行保养记录，确认记录出现在列表顶部。
6. 使用 `owner01 / labops123` 登录，确认只能查看本人负责设备的维护记录。

## 接口验收

管理员查询维护记录：

```bash
curl http://localhost:8000/api/v1/maintenance-records \
  -H "Authorization: Bearer <admin-token>"
```

设备负责人查询自己负责设备：

```bash
curl "http://localhost:8000/api/v1/maintenance-records?device_id=<owned-device-id>" \
  -H "Authorization: Bearer <owner-token>"
```

设备负责人查询非本人负责设备应返回 403。
