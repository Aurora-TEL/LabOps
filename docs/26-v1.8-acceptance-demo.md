# v1.8 验收与演示手册

## Docker 验证

所有验证保持容器内执行：

```bash
docker compose up -d --build
docker compose exec backend alembic upgrade head
docker compose exec backend python -m app.db.seed
docker compose run --rm -e PYTHONDONTWRITEBYTECODE=1 backend pytest -p no:cacheprovider
docker build --target build -t labops-frontend-build-check ./frontend
```

## 页面验收

1. 使用 `admin / password` 登录。
2. 进入 `/analytics` 数据分析页。
3. 确认页面显示 KPI、趋势图、分布图、设备健康排行和健康明细。
4. 修改开始日期和结束日期后点击刷新，确认报表重新加载。
5. 点击“近 7 天”和“近 30 天”，确认统计区间变化。
6. 点击“导出”，确认生成 CSV 文件。

## 接口验收

使用 Swagger 或接口工具验证：

```text
GET /api/v1/analytics/operation-report?start_date=2026-06-01&end_date=2026-07-31
```

验收点：

- 管理员、实验室管理员可访问。
- 设备负责人可访问，但只返回本人负责设备范围。
- 普通用户访问返回 `403`。
- `end_date < start_date` 返回业务错误。
- 超过 62 天的范围会被后端裁剪为最多 62 天。

## Fallback 验收

可停止后端模拟接口不可用：

```bash
docker compose stop backend
```

刷新 `/analytics`，页面应切换为演示数据，并显示“演示数据”来源标识。

恢复后端：

```bash
docker compose start backend
```

## 通过标准

- 后端 pytest 通过。
- 前端 Docker build 通过。
- `/analytics/operation-report` 可正常返回报表。
- 分析页 API 可用时显示后端数据，API 不可用时显示演示数据。
- 页面不依赖宿主机 `node_modules` 或本地构建产物。
